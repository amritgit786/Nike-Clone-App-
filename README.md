# 👟 Nike Landing Page — React + Tailwind CSS

A responsive, component-driven product landing page inspired by Nike, built with **React**, **Vite** and **Tailwind CSS**.

## ✨ Highlights

- Mobile-first, fully responsive layout using Tailwind CSS utility classes
- Interactive hero with shoe selector that swaps the featured product image
- Sections: Hero · Popular Products · Super Quality · Services · Special Offer · Customer Reviews · Subscribe · Footer
- Reusable components (`Button`, `Nav`, `ShoeCard`, `PopularProductCard`, `ServiceCard`, `ReviewCard`) driven by data in `src/constants`

## 🏗️ Structure

```
src/
├── components/   # Reusable UI building blocks
├── sections/     # Page sections composed from components
├── constants/    # Content data (products, services, reviews, nav links)
└── assets/       # Images and icons
```

## 🚀 Getting started

```bash
git clone https://github.com/amritgit786/Nike-Clone-App-.git
cd Nike-Clone-App-
npm install
npm run dev
```
